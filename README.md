# Shiori 栞 — читалка ранобэ

Сайт для чтения ранобэ (лайт-новелл) с тёмной анимированной темой в японском стиле:
каталог с умным поиском, удобная читалка, личный кабинет и админ-панель, в которой
администратор публикует тайтлы, делит их текст на главы и удаляет.

## Что умеет

**Для читателей**

- **Главная**: слайдер «Выбор редакции» с веером обложек, которые наклоняются за курсором,
  летящие искры, бегущие строки, свежие главы, тренды, топ по оценкам, жанры, новинки.
- **Каталог и поиск**: фильтры по статусу, жанрам (повторный клик исключает жанр), стране
  и возрасту, сортировки, сетка или список. Поиск прощает опечатки, понимает транслит
  (`mayak` → «маяк») и текст, набранный не в той раскладке (`vfzr` → «маяк»).
  Быстрый поиск открывается из любого места по `Ctrl+K` или `/`.
- **Страница тайтла**: описание, теги, оглавление по томам, прогресс, оценка от 1 до 10,
  полки (Читаю / В планах / Прочитано / Отложено / Брошено), «любимое», «поделиться»,
  похожие тайтлы.
- **Читалка**:
  - два режима: лента и постраничное листание (касанием края экрана, свайпом, стрелками, колёсиком);
  - 6 тем страницы, 6 шрифтов, размер текста, интервалы, ширина колонки, красная строка,
    выравнивание по ширине, переносы, затемнение экрана;
  - запоминает место в каждой главе и предлагает продолжить;
  - закладки с цитатой, озвучка текста голосом браузера, полноэкранный режим;
  - горячие клавиши: `←` `→` главы или страницы, `C` оглавление, `S` настройки,
    `B` закладка, `T` озвучка, `F` полный экран.
- **Вход и регистрация**: проверка никнейма, индикатор надёжности пароля, восстановление
  пароля по email (в облачном режиме).
- **Личный кабинет**: баннер с выбранной «аурой», уровень читателя и опыт, статистика
  (главы, время, серия дней), календарь активности, любимые жанры, библиотека по полкам,
  история чтения, закладки с заметками, 12 достижений, настройки профиля, аватар,
  смена email и пароля, светлая и тёмная тема сайта, режим «меньше анимаций».
- **Сообщество**: поиск читателей по нику, друзья и заявки, публичные профили
  с титулами и коллекцией карточек, обсуждение тайтлов и комментарии к главам с ответами.
- **Кейсы и карточки**: бесплатный кейс раз в неделю, открытие с прокруткой ленты,
  карточки персонажей пяти редкостей (обычная → мифическая), коллекция с прогрессом,
  обмен карточками между читателями, покупка кейсов через @CryptoBot в Telegram.

**Для администратора** (раздел «Админка»)

- Создание и редактирование тайтлов с живым предпросмотром обложки: загрузите картинку
  или соберите фирменную обложку из палитры, японского узора и иероглифа.
- Черновики и публикация, «выбор редакции» для слайдера на главной, удаление тайтлов.
- Главы: редактор с разметкой и предпросмотром в стиле читалки, автосохранение черновика,
  массовая публикация и удаление.
- **Импорт и разбивка**: вставьте весь том или загрузите `.epub` / `.fb2` / `.docx` / `.txt` /
  `.md` / `.html`. В EPUB и FB2 главы берутся из структуры книги, остальной текст
  сам разделится на главы по заголовкам («Глава 12», «Chapter 3», «Пролог», «Эпилог»…),
  по нумерации, по разделителю `***`, по объёму или по своему шаблону. Перед импортом
  можно поправить названия и номера и снять лишние части.
- **Карточки и кейсы**: персонажи с картинкой и редкостью, кейсы с ценой, весами редкостей
  и привязкой к тайтлу, бесплатный еженедельный кейс.
- **Титулы**: создаются в админке и выдаются читателям — например, за прочтение тайтла
  (в карточке читателя видно, сколько глав каждого тайтла он прочитал).
- **Пользователи**: права администратора, правка чужих профилей, выдача титулов, кейсов
  и карточек, просмотр коллекции.

## Быстрый старт

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно `http://localhost:5173`).

Без настройки сайт работает в **демо-режиме**: в каталоге сразу есть карточки «Добро пожаловать
в класс превосходства» (1-й и 2-й год), а аккаунты, библиотека и всё, что опубликовал
администратор, хранятся в браузере (IndexedDB). **Первый зарегистрированный аккаунт становится
администратором.** Текст глав в карточках не входит: загрузите его в «Админке» → тайтл →
«Импорт и разбивка» (файлы `.txt`, `.md` или `.fb2`).

Сборка для продакшена:

```bash
npm run build      # результат — в папке dist/
npm run preview    # посмотреть собранную версию
```

## Облачный режим: общий сайт для всех читателей

Чтобы администратор публиковал тайтлы, а читатели видели их со своих устройств, нужна
бесплатная база Supabase. Свой сервер писать не нужно.

1. Создайте проект на [supabase.com](https://supabase.com).
2. Откройте **SQL Editor → New query**, вставьте содержимое
   [`supabase/schema.sql`](supabase/schema.sql) целиком и нажмите **Run**. Скрипт создаст
   таблицы, права доступа (RLS), триггеры счётчиков и хранилища для обложек и аватаров.
   Его можно запускать повторно — **после каждого обновления сайта выполните его снова**:
   он добавит новые таблицы (друзья, комментарии, карточки, кейсы) и ничего не удалит.
3. Скопируйте `.env.example` в `.env.local` и вставьте `VITE_SUPABASE_URL` и
   `VITE_SUPABASE_ANON_KEY` из **Project Settings → API**.
4. Перезапустите `npm run dev`.
5. Зарегистрируйтесь: **первый аккаунт в проекте получает права администратора**.
   Затем в «Админке» нажмите «Стартовые тайтлы», чтобы добавить карточки «Класса превосходства»,
   или создайте свой тайтл.

Полезные настройки Supabase:

- **Authentication → URL Configuration**: укажите адрес сайта в *Site URL* и добавьте
  `https://ваш-сайт/reset-password` в *Redirect URLs* — для писем подтверждения и сброса пароля.
- **Authentication → Providers → Email**: если не нужно подтверждать email при регистрации,
  выключите *Confirm email*.
- Выдать права администратора вручную:
  ```sql
  update public.profiles set role = 'admin'
  where id = (select id from auth.users where email = 'you@example.com');
  ```

Права проверяются на сервере: читать опубликованное могут все, менять каталог — только
администраторы, а полки, историю, оценки и закладки видит только их владелец.

## Свой сервер в России

Пошаговая инструкция для VPS (Timeweb Cloud, Москва; около 1 200 ₽ в месяц): Supabase на том же
сервере, HTTPS, почта для писем, обновление сайта одной командой и резервные копии —
[DEPLOY.md](DEPLOY.md). Для читателей из России этот вариант надёжнее: Vercel и облачный Supabase
там замедляют или блокируют.

## Кейсы за криптовалюту (@CryptoBot)

Работает в облачном режиме, когда сайт размещён на Vercel: счёт выставляет серверная
функция [`api/cryptobot.ts`](api/cryptobot.ts), цена берётся из базы.

1. В Telegram откройте [@CryptoBot](https://t.me/CryptoBot) → **Crypto Pay** → **Create App**
   и скопируйте токен (для тестов — [@CryptoTestnetBot](https://t.me/CryptoTestnetBot)).
2. В Vercel → **Settings → Environment Variables** добавьте:
   - `CRYPTOBOT_TOKEN` — токен приложения (только сюда, не в код: репозиторий публичный);
   - `SUPABASE_SERVICE_ROLE_KEY` — служебный ключ из Supabase (**Project Settings → API Keys**,
     вкладка Legacy, `service_role`); если подключена интеграция Supabase, он уже есть;
   - `CRYPTOBOT_NETWORK=testnet` — только для тестового бота.
3. **Deployments → ⋯ → Redeploy**. Проверка: `https://ваш-сайт/api/cryptobot` должен
   показать `"configured": true`.
4. Необязательно: в @CryptoBot → Crypto Pay → ваше приложение → **Webhooks** укажите
   `https://ваш-сайт/api/cryptobot` — тогда кейсы зачисляются сразу после оплаты. Без
   вебхука они зачисляются, когда читатель возвращается на сайт или нажимает «Я оплатил».

## Деплой на Vercel

1. **Add New → Project**, выберите этот репозиторий.
2. Фреймворк Vite определится сам.
3. В **Environment Variables** добавьте `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY`.
4. **Deploy**. Файл `vercel.json` уже настраивает переходы по ссылкам внутри сайта.

Для Netlify подойдёт папка `dist` после `npm run build` (файл `public/_redirects` уже есть).

## Формат текста глав

Обычный текст, каждая строка — абзац. Дополнительно:

| Разметка | Что получится |
|---|---|
| `* * *`, `***`, `---` или `⁂` на отдельной строке | смена сцены (орнамент) |
| `> текст` | цитата, письмо, записка |
| `# Подзаголовок` | подзаголовок внутри главы |
| `*курсив*`, `_курсив_`, `**жирный**` | выделение в абзаце |
| `![Подпись](https://…/image.jpg)` | иллюстрация (по нажатию открывается крупно) |

## Структура

```
shiori/
├── supabase/schema.sql      база данных, права доступа и триггеры для облачного режима
├── src/
│   ├── lib/api/             данные: local.ts (браузер), supabase.ts (облако), общий интерфейс
│   ├── lib/search.ts        нечёткий поиск: опечатки, транслит, раскладка
│   ├── lib/text.ts          разметка глав, подсчёт слов, деление текста на главы, FB2
│   ├── lib/stats.ts         статистика читателя, уровни и достижения
│   ├── lib/seed.ts          стартовый каталог: карточки тайтлов без текста глав
│   ├── lib/books.ts         чтение EPUB, DOCX и HTML для импорта глав
│   ├── lib/collect.ts       редкости, шансы кейсов, цены, цвета титулов
│   ├── components/          интерфейс, эффекты, обложки, читалка, графики кабинета
│   └── pages/               главная, каталог, тайтл, читалка, вход, кабинет, админка
├── api/cryptobot.ts         серверная функция Vercel: счета @CryptoBot и зачисление кейсов
└── vercel.json
```

Стек: React 18, TypeScript, Vite, Tailwind CSS, Framer Motion, TanStack Query, Zustand,
React Router, Supabase.

Обложки, для которых не загружена картинка, рисуются кодом из узоров и иероглифов.
